# PhotonFiber Infrastructure

Infrastructure as Code (IaC) repository for Photon Fiber Networks.

## Objectives

- Deploy infrastructure using OpenTofu
- Configure servers using Ansible
- Host Mailcow on Microsoft Azure
- Automate deployments
- Maintain everything in Git

## Project Status

🚧 Under Development

## Technology Stack

- OpenTofu
- Ansible
- Microsoft Azure
- Ubuntu Server 24.04 LTS
- Docker
- Mailcow
